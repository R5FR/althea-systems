🔹 USER
User

id (UUID / PK)

first_name (varchar 100)

last_name (varchar 100)

email (varchar 255, unique, index)

password_hash (varchar 255)

account_status (enum : active, inactive, pending, banned)

default_payment_method_id (FK → PaymentMethod.id, nullable)

created_at (datetime)

updated_at (datetime)

last_login_at (datetime)

email_verified_at (datetime, nullable)

role (enum : user, admin)

⚠️

nombre de commandes → calculé via relation Order

CA total généré → calculé via SUM(Order.total_ttc WHERE status=paid)
